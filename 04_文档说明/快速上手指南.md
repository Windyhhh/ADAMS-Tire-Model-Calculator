# ADAMS轮胎模型计算器 - 快速上手指南

## 🚀 5分钟快速上手

### 第一步：启动程序
1. 进入 `03_打包文件/dist/` 目录
2. 双击 `ADAMS轮胎模型计算器_最终版.exe`
3. 等待程序启动（3-5秒）

### 第二步：使用默认参数
程序启动后会显示推荐的默认参数：
```
垂直载荷Fz = 400 N
外倾角γ = 13°
滑移率κ = 60%
侧偏角α = 20°
胎体侧向刚度 = 900 N/m
有效滚动半径 = 0.3406 m
滚动阻力系数 = 0.3
```

### 第三步：执行计算
1. 点击 **"计算"** 按钮
2. 等待1-2秒计算完成
3. 查看结果：
   - Fx ≈ 116 N（纵向力）
   - Fy ≈ 171 N（侧向力）
   - Mz ≈ 4.5 N·m（回正力矩）

### 第四步：观察图表
程序会显示6个图表：
- **前3个图表**：显示S型轮胎特性曲线
- **第4个图表**：显示线性关系
- **后2个图表**：显示小幅波动

### 第五步：生成TIR文件（可选）
1. 点击 **"生成TIR"** 按钮
2. 选择保存位置
3. 输入文件名（如：`test_tire.tir`）
4. 点击保存

**🎉 恭喜！您已经完成了第一次轮胎计算！**

## ❓ 快速问题解决

### Q: 程序无法启动？
**A**: 以管理员身份运行exe文件

### Q: 计算结果为0？
**A**: 检查参数是否在合理范围内，重新点击"计算"

### Q: 图表显示直线？
**A**: 调整外倾角γ到10-20°范围

### Q: TIR文件生成失败？
**A**: 选择桌面作为保存位置，使用简单文件名

## 🎓 进阶使用

### 参数调整建议
1. **载荷影响**：增大Fz会增大所有力和力矩
2. **外倾角影响**：γ主要影响BCDE系数计算
3. **滑移率影响**：κ主要影响纵向力Fx
4. **侧偏角影响**：α主要影响侧向力Fy和回正力矩Mz
