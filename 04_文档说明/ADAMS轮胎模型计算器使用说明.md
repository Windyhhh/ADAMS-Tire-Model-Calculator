## 🎯 软件介绍

### 功能概述
ADAMS轮胎模型计算器是一款专业的轮胎力学计算软件，基于Pacejka魔术公式，能够：

- **计算轮胎六分力**: Fx(纵向力)、Fy(侧向力)、Fz(垂直力)、Mx(倾覆力矩)、My(滚动阻力矩)、Mz(回正力矩)
- **生成TIR文件**: 符合ADAMS标准的轮胎参数文件
- **实时图表显示**: 6个图表展示轮胎特性曲线
- **参数响应分析**: 实时响应参数变化

### 技术特点
- **高精度计算**: 基于abcdef系数的BCDE参数计算
- **标准魔术公式**: 完整实现Pacejka轮胎模型
- **智能缩放**: 自动调整数值范围确保结果合理
- **中文界面**: 完全中文化的用户界面

## 📝 操作步骤

### 基本操作流程

#### 第一步：设置基本参数
1. **垂直载荷Fz**: 输入轮胎承受的垂直载荷
   - 典型范围: 400-600 N
   - 推荐值: 400 N

2. **外倾角γ**: 输入轮胎的外倾角度
   - 典型范围: 0-20°
   - 推荐值: 13°

3. **滑移率κ**: 输入纵向滑移率
   - 典型范围: -100% ~ +100%
   - 推荐值: 60%

4. **侧偏角α**: 输入侧向偏转角度
   - 典型范围: -30° ~ +30°
   - 推荐值: 20°

#### 第二步：设置高级参数
1. **胎体侧向刚度**: 轮胎侧向变形刚度
   - 典型值: 900 N/m
   - 影响: 倾覆力矩Mx的计算

2. **有效滚动半径**: 轮胎有效半径
   - 典型值: 0.3406 m
   - 影响: 滚动阻力矩My的计算

3. **滚动阻力系数**: 滚动阻力系数
   - 典型值: 0.3
   - 影响: 滚动阻力矩My的计算

#### 第三步：执行计算
1. 点击 **"计算"** 按钮
2. 等待计算完成（通常1-2秒）
3. 查看结果显示区域的数值
4. 观察6个图表的趋势变化

#### 第四步：分析结果
1. **检查数值合理性**:
   - Fx: 通常在50-300 N范围
   - Fy: 通常在100-400 N范围
   - Mz: 通常在2-10 N·m范围

2. **观察图表趋势**:
   - 前3个图表应显示S型曲线
   - 第4个图表应显示线性关系
   - 后2个图表应显示小幅波动

#### 第五步：生成TIR文件（可选）
1. 确认计算结果满意
2. 点击 **"生成TIR"** 按钮
3. 选择保存位置和文件名
4. 等待文件生成完成

## ⚙️ 参数设置

### 基本参数详解

#### 垂直载荷 Fz (N)
- **物理意义**: 轮胎承受的垂直方向载荷
- **设置建议**:
  - 轻载: 400 N
  - 标准载荷: 500 N
  - 重载: 600 N
- **影响**: 直接影响所有力和力矩的计算

#### 外倾角 γ (°)
- **物理意义**: 轮胎相对于垂直面的倾斜角度
- **设置建议**:
  - 直立: 0°
  - 轻微外倾: 5-10°
  - 明显外倾: 15-20°
- **影响**: 影响BCDE系数的计算

#### 滑移率 κ (%)
- **物理意义**: 轮胎纵向滑移的程度
- **计算公式**: κ = (v_wheel - v_vehicle) / v_vehicle × 100%
- **设置建议**:
  - 自由滚动: 0%
  - 轻微滑移: 20-40%
  - 中等滑移: 60-80%
  - 重度滑移: 100%
- **影响**: 主要影响纵向力Fx

#### 侧偏角 α (°)
- **物理意义**: 轮胎偏离行驶方向的角度
- **设置建议**:
  - 直行: 0°
  - 轻微转向: 5-10°
  - 中等转向: 15-25°
  - 急转向: 30°
- **影响**: 主要影响侧向力Fy和回正力矩Mz

### 高级参数详解

#### 胎体侧向刚度 (N/m)
- **物理意义**: 轮胎侧向变形的刚度系数
- **典型值**: 800-1200 N/m
- **影响**: 用于计算倾覆力矩Mx
- **公式**: Mx = Fz × (Fy / 胎体侧向刚度)

#### 有效滚动半径 (m)
- **物理意义**: 轮胎的有效滚动半径
- **典型值**: 0.30-0.40 m
- **测量方法**: 实际测量或查阅轮胎规格
- **影响**: 用于计算滚动阻力矩My

#### 滚动阻力系数
- **物理意义**: 轮胎滚动时的阻力系数
- **典型值**: 0.2-0.4
- **路面影响**:
  - 干燥沥青: 0.3
  - 湿滑路面: 0.4
  - 雪地: 0.5
- **影响**: 用于计算滚动阻力矩My

### 参数组合建议

#### 🎯 标准测试组合
```
Fz = 400 N      # 标准载荷
γ = 13°         # 中等外倾角
κ = 60%         # 中等滑移率
α = 20°         # 中等侧偏角
胎体侧向刚度 = 900 N/m
有效滚动半径 = 0.3406 m
滚动阻力系数 = 0.3
```

#### 🔬 极限测试组合
```
Fz = 600 N      # 最大载荷
γ = 20°         # 最大外倾角
κ = 100%        # 最大滑移率
α = 30°         # 最大侧偏角
```

#### ⚡ 线性区域测试
```
Fz = 400 N      # 标准载荷
γ = 0°          # 无外倾角
κ = 20%         # 小滑移率
α = 5°          # 小侧偏角
```

## 📊 结果解读

### 六分力结果解读

#### 纵向力 Fx (N)
- **正值**: 驱动力（加速时）
- **负值**: 制动力（减速时）
- **典型范围**: -300 ~ +300 N
- **影响因素**: 主要受滑移率κ影响

#### 侧向力 Fy (N)
- **正值**: 向右的侧向力
- **负值**: 向左的侧向力
- **典型范围**: -400 ~ +400 N
- **影响因素**: 主要受侧偏角α影响

#### 垂直力 Fz (N)
- **数值**: 通常等于输入的垂直载荷
- **小幅变化**: 受其他参数轻微影响
- **典型范围**: 398 ~ 402 N（输入400N时）

#### 倾覆力矩 Mx (N·m)
- **计算公式**: Mx = Fz × (Fy / 胎体侧向刚度)
- **物理意义**: 轮胎绕X轴的力矩
- **典型范围**: -100 ~ +100 N·m

#### 滚动阻力矩 My (N·m)
- **计算公式**: My = Fz × 有效滚动半径 × 滚动阻力系数
- **物理意义**: 轮胎滚动时的阻力矩
- **典型范围**: 30 ~ 50 N·m

#### 回正力矩 Mz (N·m)
- **物理意义**: 轮胎的自回正力矩
- **典型范围**: -10 ~ +10 N·m
- **影响因素**: 主要受侧偏角α影响

### 图表趋势解读

#### 第1个图表：κ-Fx（滑移率-纵向力）
- **趋势**: S型曲线
- **物理意义**: 轮胎纵向特性
- **关键点**:
  - κ=0时，Fx≈0（自由滚动）
  - κ增大时，Fx先增大后趋于饱和
  - 显示轮胎的牵引/制动特性

#### 第2个图表：α-Fy（侧偏角-侧向力）
- **趋势**: S型曲线
- **物理意义**: 轮胎侧向特性
- **关键点**:
  - α=0时，Fy≈0（直行）
  - α增大时，Fy先线性增长后饱和
  - 显示轮胎的转向特性

#### 第3个图表：α-Mz（侧偏角-回正力矩）
- **趋势**: S型曲线
- **物理意义**: 轮胎回正特性
- **关键点**:
  - α=0时，Mz≈0
  - α增大时，Mz先增大后减小
  - 显示轮胎的自回正能力

#### 第4个图表：α-Mx（侧偏角-倾覆力矩）
- **趋势**: 线性关系
- **物理意义**: 倾覆力矩与侧向力的关系
- **特点**: 与Fy成正比关系

#### 第5个图表：α-My（侧偏角-滚动阻力矩）
- **趋势**: 小幅波动
- **物理意义**: 滚动阻力矩基本恒定
- **特点**: 主要受载荷和轮胎参数影响

#### 第6个图表：α-Fz（侧偏角-垂直力）
- **趋势**: 小幅波动
- **物理意义**: 垂直力的微小变化
- **特点**: 围绕输入载荷小幅波动

## 📄 TIR文件生成

### TIR文件介绍
TIR文件是ADAMS软件使用的轮胎参数文件，包含了完整的轮胎模型参数。

### 生成步骤
1. **设置参数**: 确保所有输入参数正确
2. **执行计算**: 点击"计算"按钮完成计算
3. **生成文件**: 点击"生成TIR"按钮
4. **选择位置**: 在弹出的对话框中选择保存位置
5. **命名文件**: 输入文件名（建议包含参数信息）
6. **确认生成**: 点击"保存"完成生成

### TIR文件结构
```
[MDI_HEADER]
FILE_TYPE = 'tir'
FILE_VERSION = 3.0
...

[UNITS]
LENGTH = 'meter'
FORCE = 'newton'
ANGLE = 'radians'
...

[DIMENSION]
UNLOADED_RADIUS = 0.3406
...

[LONGITUDINAL]
B0 = xxx    # 纵向力参数
B1 = xxx
...
B13 = xxx

[LATERAL]
A0 = xxx    # 侧向力参数
A1 = xxx
...
A13 = xxx

[ALIGNING]
C0 = xxx    # 回正力矩参数
C1 = xxx
...
C13 = xxx
```

### 文件验证
生成TIR文件后，可以点击"验证TIR"按钮进行验证：
- **格式检查**: 验证文件格式正确性
- **参数完整性**: 检查所有必要参数是否存在
- **数值合理性**: 验证参数数值是否在合理范围内

### 在ADAMS中使用
1. 将TIR文件复制到ADAMS工作目录
2. 在ADAMS中创建轮胎模型
3. 引用生成的TIR文件
4. 运行仿真验证结果

## ❓ 常见问题

### 启动问题

#### Q: 双击exe文件没有反应？
**A**: 可能的解决方案：
1. 以管理员身份运行
2. 检查杀毒软件是否拦截
3. 确保Windows版本为10或11
4. 重新下载exe文件

#### Q: 提示缺少Python环境？
**A**: 
1. 使用exe版本无需Python环境
2. 如果运行Python脚本，请安装Python 3.8+
3. 确保安装了所需的依赖包

### 计算问题

#### Q: 计算结果显示为0或异常值？
**A**: 检查以下项目：
1. 参数是否在合理范围内
2. 数据文件是否完整（Excel表格）
3. 重新点击"计算"按钮
4. 重启程序

#### Q: 图表显示直线而不是曲线？
**A**: 
1. 检查参数设置是否合理
2. 尝试调整外倾角γ的值
3. 确保滑移率κ和侧偏角α不为0

#### Q: TIR文件生成失败？
**A**: 
1. 确保有文件写入权限
2. 检查磁盘空间是否充足
3. 先执行一次计算再生成TIR
4. 选择不同的保存位置

### 数值问题

#### Q: 计算结果与预期差异较大？
**A**: 
1. 确认输入参数的单位正确
2. 检查参数是否在推荐范围内
3. 对比标准测试组合的结果
4. 查看图表趋势是否正常

#### Q: 图表数值范围异常？
**A**: 
1. 图表会自动调整坐标轴范围
2. 检查输入参数是否过大或过小
3. 尝试使用推荐的参数组合

### 性能问题

#### Q: 程序运行缓慢？
**A**: 
1. 关闭其他大型软件
2. 确保有足够的内存
3. 使用SSD硬盘可提高性能

#### Q: 程序占用内存过大？
**A**: 
1. 定期重启程序
2. 关闭不必要的图表窗口
3. 清理系统临时文件

## 📚 技术原理简介

### BCDE系数计算原理
程序使用abcdef数据表计算BCDE系数：
```
B = a₁×Fz² + b₁×γ² + c₁×Fz×γ + d₁×Fz + e₁×γ + f₁
C = a₂×Fz² + b₂×γ² + c₂×Fz×γ + d₂×Fz + e₂×γ + f₂
D = a₃×Fz² + b₃×γ² + c₃×Fz×γ + d₃×Fz + e₃×γ + f₃
E = a₄×Fz² + b₄×γ² + c₄×Fz×γ + d₄×Fz + e₄×γ + f₄
```

### 魔术公式实现
标准Pacejka魔术公式：
```
F = D × sin(C × arctan(B×X - E × (B×X - arctan(B×X))))
```
其中：
- F: 输出力/力矩
- X: 输入变量（κ或α）
- BCDE: 魔术公式系数

### 智能缩放机制
为确保结果合理，程序实现了智能缩放：
1. 计算原始魔术公式结果
2. 根据物理约束确定缩放因子
3. 应用缩放得到最终结果
4. 保持正确的物理趋势
